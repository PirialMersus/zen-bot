# Zen Bot 🧘

Telegram-бот для осознанности, выработки полезных привычек и регулярных напоминаний.

## Возможности

- **Кастомные напоминания:** создание напоминаний с текстом, фото или видео с заданным интервалом (от минут до суток) или в точное время дня (`ЧЧ:ММ`).
- **Карточки осознанности («Указатели»):** выдача вдохновляющих цитат и карточек осознанности с поддержкой избранного.
- **Мультиязычность:** поддержка 4 языков (`ru`, `en`, `uk`, `es`) с автоматическим определением локали пользователя.
- **Тихие часы:** настраиваемый ночной период (по умолчанию 23:00–08:00 с учетом часового пояса), когда бот не беспокоит.
- **API сервер:** встроенный Express-сервер для синхронизации и интеграций.

## Стек технологий

- **Node.js** (ES Modules)
- **Telegraf** 4.x
- **Express** 5.x
- **MongoDB & Mongoose**
- **Luxon** (часовые пояса и расчет расписания)
- **Vitest** (модульное и интеграционное тестирование с `mongodb-memory-server`)

## Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Скопируйте пример конфигурации и заполните параметры:

```bash
cp .env.example .env
```

Обязательные переменные:
- `BOT_TOKEN` — токен бота от @BotFather.
- `MONGO_URI` — строка подключения к MongoDB.
- `JWT_SECRET` — секретный ключ для API (от 32 символов).
- `CREATOR_ID` — Telegram ID администратора бота.

### 3. Наполнение базы указателей

```bash
npm run seed:pointers
npm run sync:pointers
```

### 4. Запуск в режиме разработки

```bash
npm run dev
```

### 5. Запуск тестов

```bash
npm test
```

## Доступные npm-скрипты

- `npm start` — боевой запуск бота и API сервера.
- `npm run dev` — запуск с автоперезагрузкой через nodemon.
- `npm test` — запуск тестов Vitest.
- `npm run test:watch` — интерактивный запуск тестов при изменении файлов.
- `npm run lint` — проверка кодовой базы через ESLint.
- `npm run format` — форматирование кода с помощью Prettier.
- `npm run seed:pointers` — первичное наполнение базы указателей.
- `npm run sync:pointers` — синхронизация указателей по всем языкам.

## Структура проекта

```text
├── scripts/             # Скрипты обслуживания и наполнения БД
│   └── migrations/      # Разовые скрипты миграций БД
├── src/
│   ├── api/             # Маршруты и контроллеры REST API
│   ├── constants/       # Тексты, кнопки, интерфейсные строки и таймзоны
│   ├── handlers/        # Обработчики команд, сообщений и callback-кнопок
│   ├── keyboard/        # Инлайн- и reply-клавиатуры
│   ├── middlewares/     # Middleware активности, кэширования и языка
│   ├── models/          # Схемы данных Mongoose (User, Reminder, Pointer, Activity)
│   ├── services/        # Бизнес-логика, доставка и планировщик
│   ├── utils/           # Вспомогательные утилиты
│   ├── bot.js           # Инициализация Telegraf бота и роутинг
│   ├── server.js        # Инициализация Express приложения
│   └── index.js         # Главная точка входа приложения
└── tests/               # Тесты (Unit, Integration, Stress, Isolation)
```
